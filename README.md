# Eventora – Event Planning Management System

A complete event planning planner that works in any browser.

**Open the app:** https://eventoraplanner.github.io

## Features
- Events, calendar, clients, leads, proposals, guests & RSVP, seating plan, day-of timeline
- Vendors, tasks, templates, food & beverage, styling, talent, equipment, inventory, travel
- Budget, payments & invoices, ticketing, sponsors, messaging hub
- Staff, meetings, documents, risks, permits, wrap-up and reports
- 9 colour themes, light & dark mode
- **Link devices:** use it on your phone and computer with one 6-digit code

## Your data
Everything is saved in your own browser. Linked devices send changes directly to each other. Use **Settings → Data & backup** to back up.
